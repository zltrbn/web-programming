# 📌 ToDo List

Веб-приложение для управления задачами.  
Реализовано на **чистом JavaScript** с использованием DOM API.  

Позволяет:
- создавать, редактировать и удалять задачи,
- отмечать их как выполненные,
- сортировать, фильтровать и искать,
- менять порядок drag-and-drop.  

Все данные сохраняются в **localStorage** и восстанавливаются при загрузке страницы.

---

## 🚀 Функционал

- ➕ Добавление новой задачи  
- ❌ Удаление задачи  
- 🖊 Редактирование задачи (текст и дата)  
- ✅ Отметка задачи как выполненной  
- 📅 Сортировка задач по дате  
- 🔍 Поиск по названию и дате  
- 🗂 Фильтрация по статусу (выполненные / невыполненные / все)  
- 💾 Сохранение задач в localStorage  
- 🎯 Перетаскивание задач drag-and-drop
