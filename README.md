# 🌦 Weather App — Лабораторная работа

Приложение для получения прогноза погоды по названию города с использованием API OpenWeather.  
Проект реализован на **чистом JavaScript** с модульной архитектурой (ES Modules).

---

## 📌 Функциональность

- Ввод города вручную  
- Автодополнение популярных городов  
- Загрузка прогноза с OpenWeather API  
- Отображение температуры, описания и иконки погоды  
- Поддержка нескольких сохранённых локаций  
- Сохранение данных в LocalStorage  
- Обработка ошибок: город не найден, ошибка сети, некорректный ввод  

---

## 🔧 Используемые технологии

- HTML5  
- CSS3  
- JavaScript (ES6+)  
- OpenWeather API  
- ES Modules  

---

## 🧩 Модули проекта

### `api.js`
- Выполняет запросы к **OpenWeather API**
- Получает координаты города (geocoding)
- Загружает прогноз погоды
- Обрабатывает сетевые ошибки
- Возвращает данные в формате JSON

### `uiController.js`
- Безопасно создаёт DOM-элементы (без `innerHTML`)
- Генерирует карточки прогноза
- Обновляет список сохранённых городов
- Формирует элементы интерфейса для каждого дня прогноза

### `events.js`
- Обрабатывает ввод пользователя
- Реагирует на выбор города из подсказок
- Запускает загрузку прогноза
- Навешивает обработчики событий на UI

### `state.js`
- Хранит состояние приложения
- Содержит выбранный город и сохранённые локации
- Передаёт данные между модулями
- Управляет текущей карточкой прогноза

### `storage.js`
- Работает с **LocalStorage**
- Сохраняет/загружает список городов
- Экспортирует состояние при запуске
- Обеспечивает персистентность приложения

## 🧪 Логика работы

Приложение получает погодные данные по координатам или названию города, используя OpenWeather API, и отображает краткий прогноз на три дня. Работа строится вокруг трёх основных процессов:

1. **Определение локации**
   - Приложение запрашивает геолокацию пользователя.
   - Если доступ запрещён — предлагает ввести город вручную.
   - При вводе текста показываются подсказки с возможными городами.

2. **Загрузка данных**
   - По координатам выполняется запрос к API `/forecast`.
   - Выбираются три временные точки:  
     - текущий момент  
     - +24 часа  
     - +48 часов  
   - Данные преобразуются в удобный формат для отображения.

3. **Отрисовка интерфейса**
   - На основе шаблона создаются карточки городов.
   - Для каждого дня добавляется:
     - дата и день недели  
     - иконка погоды  
     - температура  
   - Карточки обновляются без использования `innerHTML` (всё создаётся через DOM).
