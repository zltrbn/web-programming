# 2048 — Vanilla JS (OOP + Modules)

Этот проект представляет собой реализацию игры **2048** на JavaScript с использованием **ООП** и **модульной архитектуры**. Код разделён на независимые модули: игровая логика, интерфейс, управление событиями и работа с локальным хранилищем.

---

## 🚀 Функциональность

- управление стрелками и свайпами  
- кнопки **Restart** и **Undo**  
- корректный откат предыдущего хода  
- отображение текущего счёта и рекорда  
- модальное окно при проигрыше  
- ввод имени и сохранение результата  
- таблица лидеров 
- адаптивное игровое поле 4×4  

---

## 🧩 ООП-архитектура проекта

### **1. Game (game.js)**
Основная логика:
- игровое поле (матрица)
- движение и объединение плиток
- создание новых значений
- подсчёт очков
- проверка на проигрыш
- сохранение и восстановление состояния (undo)

---

### **2. UI (ui.js)**
Отвечает за DOM:
- отрисовка игрового поля
- обновление счёта и рекорда
- показ/скрытие модального окна
- отображение таблицы лидеров  
В этом классе нет игровой логики — только интерфейс.

---

### **3. Storage (storage.js)**
Работа с LocalStorage:
- хранение рекорда
- хранение таблицы лидеров
- добавление новых результатов
- получение топ-5 игроков

---

### **4. Controls (controls.js)**
Занимается обработкой событий:
- клавиатура
- кнопки (restart, undo)
- элементы модального окна
- связь между Game и UI

---

### **5. Main (main.js)**
Точка входа:
- создаёт экземпляры Game, UI, Storage, Controls
- соединяет модули
- запускает игру
